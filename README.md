# explorer-platform

CDK + Amplify hosting for the explorer app. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/explorer-platform-archive`.

Hardcoded **npm auth token removed** (Amplify build now reads `$NPM_TOKEN`). **Revoke that npm token.** Generated `cdk.context.json` dropped. Cognito ids and JWTs in Postman dumps redacted. p2pify RPCs replaced with public seeds. TradingView rewrite paths remain as URL strings only; the Charting Library itself is not in this repo.
